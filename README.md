One original out-of-office auto-reply, as if a houseplant sent it, for make.fun's "The Houseplant Out-of-Office" bounty ($2 in USDC). The entry: a plant that died during a meeting about synergy, whose last words were "water me".

## Run it

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
